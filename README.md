## Nome do projeto: Shimazaki Vinhos

## 📌 Descrição do Projeto

O projeto desenvolvido consiste em um sistema de cadastro e gerenciamento de vinhos utilizando JavaScript. O sistema permite cadastrar vinhos informando nome, tipo, safra e quantidade em estoque, realizando validações dos dados inseridos pelo usuário através de prompt(), alert() e console.log().

Durante o desenvolvimento foram utilizados arrays de objetos para armazenar os dados dos vinhos e funções reutilizáveis para organizar o código. Também foram aplicadas funções de alta ordem como forEach(), filter(), reduce() e map() para listar os vinhos cadastrados, identificar vinhos com estoque baixo, calcular o estoque total da vinícola e exibir os nomes dos vinhos em caixa alta.

O projeto possui uma estrutura organizada com HTML, CSS e JavaScript separados, além de uma estilização simples para apresentação da página da vinheria.
